# Natural Scroll Update

- Removed the sticky/pinned cinematic stage behavior.
- Removed the multi-step/snap-style section feel.
- Each cinematic page now behaves like a normal document section.
- Text moves naturally with the page while scrolling.
- The next section follows naturally after the cinematic section.
- The single hero image remains behind the content and animates continuously from scroll progress.
- The image uses a lightweight transform (zoom + x/y drift) rather than multiple images or heavy 3D rendering.
- Existing routes, content, theme switching, and workflow are unchanged.
