# Component references

This project keeps the visual system self-contained and restyled as one INTERIORA design language.

- **ThreeUI role:** atmospheric/background treatment is intentionally kept minimal so the cinematic scene remains the focus.
- **React Bits role:** scroll-driven text and reveal patterns inspired the motion approach.
- **UIverse role:** button/card interaction patterns informed the lightweight UI primitives.

These are design references, not copied third-party packages. The project runs as a standalone React/Vite frontend.
