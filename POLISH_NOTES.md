# INTERIORA — Polish pass

This version removes non-essential visual layers and repeated content while preserving the required five-page cinematic scroll experience.

## Kept
- Exactly five routes: Home, Residential, Commercial, Process, Portfolio.
- Scroll position continuously drives the cinematic scene.
- Animated typography and scene overlays.
- Project/gallery interactions and frontend-only contact form.
- Reduced-motion support.
- Luxury editorial visual system.

## Removed
- Global loading screen.
- Global page-transition curtain.
- Ambient canvas background.
- Custom cursor.
- Global document scroll-progress bar.
- Footer calm-mode toggle and redundant credits block.
- Duplicate portfolio card grid.

The removed effects were decorative layers that competed with the primary requirement: the room/project transformation controlled by scrolling.
